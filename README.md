A two-line robot confession, written by a small program for the
[The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59)
bounty on make.fun.

Line one is a robot apologizing in a single sentence for one specific
mistake. Line two is one sentence saying what it learned and what it will
do differently — the lesson follows from that exact mistake.

## The entry

> I watered the plastic fern on Mrs. Alvarez's balcony for eleven days, proud of how green it stayed.
>
> Now I read the tag before I lift the can, because tending something starts with knowing whether it is alive.

## Run

```sh
python3 main.py
```

The program writes the two lines to `/output/entry.txt`.
